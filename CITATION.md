# Citing PrismAPI

If you use PrismAPI in a systematic review or other published work, cite the software:

> Nasser, G. (2026). PrismAPI (version 0.1.0-beta.1) [Computer software]. https://github.com/GerardNasser/PRISMA-App

Machine-readable metadata lives in [`CITATION.cff`](CITATION.cff), which GitHub renders as a cite button. There is no archived DOI yet; when a release is archived on Zenodo, both files will carry it.

PrismAPI implements the PRISMA 2020 reporting guideline. Reviews produced with it should cite the guideline itself:

> Page MJ, McKenzie JE, Bossuyt PM, et al. The PRISMA 2020 statement: an updated guideline for reporting systematic reviews. BMJ 2021;372:n71. doi:10.1136/bmj.n71
