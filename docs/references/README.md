# PRISMA 2020 reference PDFs

These three PDFs are the PRISMA 2020 papers, redistributed here for offline reference:

- `PRISMA_2020_explanation_and_elaboration.pdf` — Page MJ, Moher D, Bossuyt PM, et al. PRISMA 2020 explanation and elaboration: updated guidance and exemplars for reporting systematic reviews. BMJ 2021;372:n160. doi:10.1136/bmj.n160
- `PRISMA_2020_examples.pdf` — supplementary examples to the explanation and elaboration paper.
- `PRISMA_2020_expanded_checklist.pdf` — the expanded PRISMA 2020 checklist, from https://www.prisma-statement.org/

The BMJ papers were published open access under the Creative Commons Attribution 4.0 licence (CC BY 4.0, https://creativecommons.org/licenses/by/4.0/), which permits redistribution with attribution. The statement paper itself is Page MJ, et al. The PRISMA 2020 statement: an updated guideline for reporting systematic reviews. BMJ 2021;372:n71. doi:10.1136/bmj.n71
